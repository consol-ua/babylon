# Gemini Live Duo Translator (macOS Desktop)

Двосторонній синхронний AI-перекладач у реальному часі для онлайн-конференцій (**Zoom**, **Google Meet**, **Microsoft Teams**, **Discord**), дублювання медіа (**YouTube**, подкасти, відео) та локального синтезу мовлення з підтримкою **клонування голосу (Voice Cloning)**.

Застосунок побудовано на базі **Tauri 2.0 (Rust)**, **React 18 (TypeScript, Tailwind CSS)**, **FastAPI (Python 3.11+)**, **Gemini Multimodal Live API** та модульного локального TTS-рушія (**Piper ONNX / Neural Voice Cloning**).

---

## 🌟 Основні можливості

### 1. 🎙️ Гібридний голосовий рушій та клонування голосу (Voice Cloning)
- **Три режими синтезу мови (незалежно для вихідного та вхідного каналів)**:
  - ☁️ **Хмарні голоси Gemini**: природне потокове звучання (Puck, Aoede, Fenrir, Kore, Charon тощо) безпосередньо з Google AI Studio.
  - 💻 **Локальні нейромережі (ONNX / Piper)**: надшвидка автономна генерація з нульовою залежністю від хмарного аудіо (`Лада UK`, `Lessac EN`).
  - 🧬 **Клонування голосу (Zero-Shot Voice Cloning)**: синтез мови зі збереженням тембру, висоти тону й акустичного забарвлення оригінального спікера на основі короткого референсу.
- **Вбудований віджет запису та калібрування семплу**:
  - Запис 5–10 секунд зразка голосу з фізичного мікрофона прямо в інтерфейсі (Web Audio API) з живим VU-метром.
  - Можливість завантаження власних аудіофайлів (.wav, .mp3) для створення персональних профілів голосу.
  - Автоматична нормалізація до стандарту студійної обробки (16kHz Mono 16-bit PCM).
  - Миттєве тестове прослуховування синтезованої фрази перед виходом у дзвінок.
- **Потоковий чанкер речень (Punctuation Sentence Streamer)**:
  - Розбиття потокових токенів перекладу за розділовими знаками (`.`, `!`, `?`, `;`, `:`, `\n`).
  - Адаптивне скидання буфера за таймаутом (450 мс для фраз від 3 слів), що забезпечує мінімальну затримку відтворення без обриву речень.
  - Миттєве скидання черги синтезу у разі перебивання мови (interruption / barge-in).

### 2. 📞 Синхронний дзвінок (Live Call — Full Duplex)
- **Вихідна лінія (Мій голос: UA ➔ Співрозмовник)**:
  - Захоплює ваш голос із фізичного мікрофона.
  - Синхронно перекладає на обрану мову обраним голосом (хмарним, локальним або клонованим).
  - Транслює чистий синтезований звук у віртуальний мікрофон (**BlackHole 2ch**), який підключається в Zoom/Meet/Teams.
- **Вхідна лінія (Звук співрозмовника: Співрозмовник ➔ UA)**:
  - Перехоплює звук із динаміків конференції через **BlackHole 16ch**.
  - Перекладає українською мовою у реальному часі обраним голосом.
  - Застосовує **Smart Ducking** (плавне приглушення голосу оригіналу) та транслює у фізичні навушники.
- **Інтерактивна інструкція «Як налаштувати»**:
  - Покрокові схеми налаштувань для Zoom, Google Meet, Teams, Discord.
  - Швидке копіювання команд встановлення віртуальних аудіокабелів.
  - **Захист від закільцьовування (Loopback Prevention)**: динамічне попередження у разі вибору однакового кабелю для входу і виходу.

### 3. 🎬 Дублювання відео та медіа (Media / YouTube Dubbing)
- Окрема вкладка для перегляду та синхронного перекладу відео з YouTube, вебінарів та трансляцій.
- Можливість вибору будь-якого голосового профілю (хмарний, локальний, клонований).
- Гнучке налаштування коефіцієнта фонового звуку (**Ducking Factor**) та буфера згладжування (**Jitter Buffer**).

### 4. 🧪 Тестовий майданчик та перевірка мікрофона (Playground)
- **Вбудовані аудіо-семпли**:
  - *IT Daily Standup* (мікросервіси, бази даних, оптимізація запитів).
  - *System Architecture Interview* (високонавантажені системи, failover).
  - *Casual Small Talk* (розмовна повсякденна англійська).
  - Повний цикл дозвучування фраз (Turn Completion Drain) без обриву останніх слів.
- **Тест фізичного мікрофона**:
  - Запис голосу з мікрофона, перевірка обраного голосу озвучки, вимірювання затримки (latency в мс) та живий транскрипт.

### 5. 🎛️ DSP-обробка та телеметрія
- **Smart Ducking DSP**: інтелектуальне sidechain-приглушення з налаштуванням атаки (attack), утримання (hold) та спаду (release) для уникнення клацань та стрибків гучності.
- **Jitter Buffer (FIFO)**: регульований буфер попереднього накопичення аудіо (50–400 мс) для усунення переривань у нестабільному інтернеті.
- **Live Телеметрія**: VU-метри рівнів звуку в децибелах (dB), індикація активного Ducking, живий транскрипт оригіналу та перекладу, а також консоль системних логів.

## 🎧 Схема аудіо-маршрутизації (2 віртуальні кабелі)

```text
[Вихідна лінія - Мій голос]
Фізичний мікрофон ──► Gemini Live STT / Translation
                            │
                            ▼
               [Вибір голосу: Cloud / Local / Cloned] ──► BlackHole 2ch ──► Zoom Mic

[Вхідна лінія - Співрозмовник]
Zoom Speaker (BlackHole 16ch) ──► Gemini Live STT / Translation
                                        │
                                        ▼
                           [Вибір голосу: Cloud / Local / Cloned]
                                        │
                                        ▼
                           Smart Ducking (оригінал + переклад) ──► Фізичні навушники
```

## 📋 Системні вимоги (macOS)

1. **macOS** 12.0+ (Apple Silicon M1/M2/M3/M4 або Intel).
2. **Homebrew** (для встановлення системних пакетів):
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
3. **PortAudio** (необхідний для роботи аудіодрайвера Python):
   ```bash
   brew install portaudio
   ```
4. **Віртуальні аудіодрайвери BlackHole** (обов'язково 2ch та 16ch):
   ```bash
   brew install blackhole-2ch blackhole-16ch
   ```
5. **Node.js** (v18+) та **npm**.
6. **Python** (3.11 або 3.12).
7. **Rust & Cargo** (для компіляції Tauri):
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```
8. **Gemini API Key**: отримайте ключ у [Google AI Studio](https://aistudio.google.com/).

## 🚀 Інструкція із запуску проєкту

### Крок 1: Конфігурація API-ключа

Створіть файл `.env` у папці `backend` (або вкажіть API-ключ безпосередньо у графічному інтерфейсі застосунку):

```bash
echo "GEMINI_API_KEY=ваш_ключ_з_google_ai_studio" > backend/.env
```

---

### Крок 2: Запуск Python бекенду

Відкрийте **перший термінал**:

```bash
cd backend

# Створення та активація віртуального оточення
python3 -m venv venv
source venv/bin/activate

# Встановлення залежностей (включаючи ONNX Runtime, SciPy, PyAudio)
pip install -r requirements.txt

# Запуск сервера FastAPI (порт 8000)
python main.py
```
> Бекенд запуститься на `http://127.0.0.1:8000`. WebSocket доступний за адресою `ws://127.0.0.1:8000/ws`.

---

### Крок 3: Запуск клієнтського інтерфейсу

Відкрийте **другий термінал** (з кореневої директорії проєкту):

```bash
# Встановлення залежностей фронтенду
npm install

# Режим A: Швидкий запуск у браузері (Fast Refresh)
npm run dev
# Інтерфейс буде доступний за адресою: http://localhost:1420

# Режим B: Повноцінний запуск як нативного десктопного застосунку macOS (Tauri)
npm run tauri dev
```
